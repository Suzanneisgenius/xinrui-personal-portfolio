## Maintaining the site

Static, no build step; GitHub Pages serves the repository root. Before changing anything, read `HANDOFF.md` (state, rules, open items) and `docs/SKILL-minimal-portfolio-design.md` (the design system). The full version history, v4 to the current release, is in `docs/VERSION-HISTORY.md`. The quantitative finance version of the site is a separate repository, [Xinrui-Portfolio](https://github.com/Suzanneisgenius/Xinrui-Portfolio); the two share a design system and are maintained apart.
